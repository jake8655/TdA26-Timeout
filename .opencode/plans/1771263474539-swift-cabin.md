# Frontend audit plan (apps/web only)

## Goal
Address the UX/consistency feedback described in the TEAM RESULTS json files, but apply improvements to the existing pages only. Focus areas: appearance/design, typography, layout/spacing, consistency/standards, user feedback/empty states, and SEO/legal basics. No other apps/services touched.
Ignore all feedback not related to the frontend and everything that already has max points.

## Scope (target files)
- Global layout/metadata: `apps/web/src/app/layout.tsx`
- Global styles/theme tokens: `apps/web/src/styles/globals.css`
- Header/navigation: `apps/web/src/components/header.tsx`
- Footer/legal links: `apps/web/src/components/footer.tsx`
- Home page sections: `apps/web/src/app/page.tsx`, `apps/web/src/components/home/*`
- Courses listing/detail: `apps/web/src/app/courses/page.tsx`, `apps/web/src/app/courses/[uuid]/page.tsx`, `apps/web/src/components/courses/*`
- Dashboard overview/detail: `apps/web/src/app/dashboard/page.tsx`, `apps/web/src/app/dashboard/courses/[uuid]/page.tsx`
- Quiz UI/feedback: `apps/web/src/components/quizzes/quiz-player.tsx`, `apps/web/src/components/quizzes/quiz-question.tsx`, `apps/web/src/components/quizzes/quiz-stats-dialog.tsx`, `apps/web/src/components/quizzes/quiz-stats-question.tsx`
- 404: `apps/web/src/app/not-found.tsx`

## Plan
1. **Consistency + standards (layout, components, spacing)**
   - Unify card/container treatments across pages by consolidating on existing UI components (Card, Dialog, Button) and consistent component-level class usage so course cards, quiz cards, stats, and empty states share a coherent pattern.
   - Normalize header + section spacing to a consistent vertical rhythm on `Home`, `Courses`, `Course Detail`, `Dashboard`, and `Dashboard Course Detail` using component composition rather than new global utility classes.

2. **Appearance + design polish**
   - Update empty states (courses, materials, quizzes, stats) to share a consistent pattern: icon + title + short description + primary action where applicable.
   - Improve visual separation between stacked sections (subtle dividers, spacing adjustments) to reduce dense content blocks.

3. **Typography + readability**
   - Standardize heading sizes and body text scales across pages; reduce uneven jumps between `text-2xl`, `text-3xl`, `text-4xl` usage.
   - Improve line-height and maximum line length for dense content (course descriptions, quiz questions) to increase readability.
   - Make muted text contrast more consistent by adjusting component-level class usage (avoid changing global tokens unless absolutely required).

4. **User feedback + states**
   - Improve loading and error states to be more actionable (e.g., add “Retry” actions where appropriate).
   - Make quiz result feedback clearer: highlight correct/incorrect options more consistently and show summary text + score badge.
   - Ensure “no data” states in stats dialog and dashboard sections are visually distinct and friendly.

5. **Navigation clarity**
   - Improve top nav clarity for authenticated users (e.g., add “Dashboard” and “Courses” quick link cluster or clearer CTA hierarchy).
   - Ensure the login state has a consistent action button style between header and dashboard CTA buttons.

6. **SEO + legal basics**
   - Expand metadata in `layout.tsx`: add `metadataBase`, `openGraph`, `twitter`, and `robots` values.
   - Add simple in-app legal routes (e.g., `/privacy`, `/terms`) with minimal content and link them in the footer. Mention Copyright, Contact, ToU and GDPR in those pages.
   - Confirm favicon usage (already present at `apps/web/src/app/favicon.ico`).

## Implementation details (by area)
- **Global metadata:** Update `layout.tsx` with richer metadata and consistent title template; ensure dark theme is explicit in viewport metadata.
- **Global tokens:** Avoid adding new global classes; only touch `globals.css` if required for accessibility/contrast, otherwise keep styling consistency at component level.
- **Header:** Slightly adjust navigation text styles, spacing, and CTA hierarchy; ensure active/hover states are consistent with button tokens.
- **Footer:** Add privacy/terms links; consider small “Contact” details alignment improvements.
- **Legal pages:** Create `apps/web/src/app/privacy/page.tsx` and `apps/web/src/app/terms/page.tsx` using existing page layout patterns.
- **Courses page:** Align empty/failed/loaded states to consistent layout; improve hero section alignment and search input container spacing; standardize cards.
- **Course detail pages:** Add section separators and consistent headers for Quizzes/Feed/Materials; tune description width and spacing.
- **Dashboard pages:** Standardize section headers (title + action), refine empty states to match courses page, align card styling with course cards.
- **Quiz UI:** Improve option styles and feedback contrast; add a short summary block after submission for clarity.
- **Stats dialog:** Standardize cards/rows, improve “no submissions” content to match empty state pattern.
- **404 page:** Minor adjustments to bring in the same typography scale and consistent CTA styling.

## Verification

  - Check Home, Courses, Course Detail, Dashboard, Dashboard Course Detail, Login, Quiz flow, Stats dialog, and 404 pages for consistent spacing, typography, and empty states.
  - Validate metadata output in `layout.tsx` for title/description/OpenGraph/Twitter.
